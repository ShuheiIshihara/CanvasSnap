# coderabbit-review.md

## 必須事項
- 必ず `coderabbit --prompt-only` コマンドを実行すること
- このコマンドは既にインストール済み
- 自分でレビューを行わないこと

## 手順

1. 以下のコマンドを実行：
```bash
   ~/.local/bin/coderabbit --prompt-only
```

2. コマンドの出力結果を確認

3. 指摘事項がある場合：
   - 該当コードを修正
   - 再度手順1のコマンドを実行

4. 指摘事項がない場合：
   - 「レビュー完了」と報告

## 制約
- 最大5回までループ
- コマンドがエラーになった場合はエラー内容を報告
